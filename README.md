This project investigates the feasibility of cross-nationality keystroke dynamics authentication, developing a machine learning system capable of classifying individuals based on their typing rhythm across six nationality groups. Keystroke dynamics, the study of how individuals type, has long been recognised as a behavioural biometric that can complement or replace traditional authentication mechanisms such as passwords. However, most existing research focuses on homogeneous user populations, leaving a gap in understanding how nationality influences typing patterns.
This project used the KeyRecs dataset, comprising 562,372 keystroke pairs from 99 participants spanning 20 nationalities, as the primary data source. The study extended this dataset by collecting original data from 12 Albanian participants (p100-p111), a nationality not adequately represented in the original dataset, bringing the total to 111 participants across 6 nationality groups: Poland, Portugal, Greece, Italy, South Africa, and Albania.
A comprehensive feature engineering pipeline was developed, extracting 25 statistical features from keystroke timing data including dwell time, flight time, up-down timing, and derived features such as coefficient of variation, rhythm score, and speed index. A windowed approach with a window size of 50 keystrokes and step size of 10 was applied to the free-text typing data, generating approximately 40,000 training samples. Data augmentation was applied to the Albanian dataset using Gaussian noise injection, producing 15 variants per participant to address class imbalance. SMOTE oversampling was additionally applied across all six classes.
Through empirical comparison of six machine learning algorithms, the Random Forest classifier with 500 estimators was identified as the optimal model, achieving a test accuracy of 83.81% and a cross-validation accuracy of 82.88% (plus or minus 0.47%). The system achieved an Equal Error Rate (EER) of 1.09%, an Area Under the Curve (AUC) of 0.9995, and demonstrated a 97.78% attack defence rate against zero-effort, statistical, and targeted adversarial attacks.
The system was implemented as a full-stack web application using Flask and vanilla JavaScript, providing a real-time interactive demonstration of keystroke dynamics authentication with six tabs covering authentication, enrolment, typist comparison, attack simulation, ROC curve analysis, and data collection. The data collection module enables continuous dataset extension with automatic model retraining, establishing a self-improving system architecture.
The findings confirm that nationality-level typing pattern classification is feasible at above 80% accuracy, with implications for adaptive authentication systems, regional security policy, and the development of more inclusive biometric datasets.
