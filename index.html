How It Works

1

Keystroke Capture

Your browser records exact timestamps for every key press and release using the Web Performance API, accurate to sub-millisecond precision.

2

Feature Extraction

Dwell time = how long each key is held. Flight time = gap between releasing one key and pressing the next. 13 statistical features (mean, std, median, IQR, CV) are computed.

3

Random Forest Classification

Features are sent to the local Flask API which runs your 6 trained Random Forest models (500 trees each), specialised for different nationality groups.

4

Confidence Scoring

Each model votes via its 500 trees. Mean probability and variance across trees are combined. Feature importances are extracted directly from the winning model's .feature_importances_ attribute.

5

Accept / Reject Decision

If the top model's confidence exceeds the threshold (default 60%), the user is authenticated. The EER of 1.09% means the system makes very few errors at the optimal threshold.
